# 学习日志索引（docs/learn/）

> **用途**：本项目排障/实现过程中沉淀下来的**可复现记录**与**可迁移规律**。
> **与工作日志的分工**：`docs/worklog/YYYY-MM-DD.md` 记「今天做了什么、验证到什么程度」；
> 这里记「这个问题为什么发生、怎么定位、下次怎么避免」——**报错原文 + 可复现探针 + 根因 + 前后对比 + 验证证据**是硬要求。
> **写法纪律**（源自全局协作记忆）：实测与推断分开标注；遗留风险与「待用户决定」单列，不粉饰。
> **维护**：新增一篇后回到本文件补一行索引，并在「通用规律登记」里登记跨条目规律。
