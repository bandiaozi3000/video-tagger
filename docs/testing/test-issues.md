# 问题清单

### [#1] 「最近观看」下勾选「待确认」筛选无效（同根因：状态筛选也无效）
- **日期**：2026-08-06
- **模块**：媒体管理
- **严重程度**：🟧 一般
- **复现步骤**：
  1. 切到「最近观看」tab
  2. 勾选「待确认」筛选复选框
  3. 观察媒体列表：仍显示全部最近观看媒体，未按 `confirmed=0` 过滤
- **期望行为**：只显示未确认（confirmed=0）的媒体
- **实际行为**：筛选被静默忽略，列表照常
- **根因（已读码）**：`loadMedia()`（app.js:956-965）在 `mediaMode==='recent'` 分支 url 恒为 `/api/media/recent?limit=100`，不带 `confirmed=0`；客户端兜底过滤（app.js:971-976）只覆盖 format/subcategory，**漏了 unconfirmed**。
- **状态**：🟩 已修复（2026-08-06，代码完成+单测通过；待用户实测确认 + 提交）
- **备注**：修复方案：后端 `/api/media/recent` 与 `/api/collections/{id}/media` 支持 `status`/`confirmed`（recent 另支持 `collectionId`）参数（MediaMapper.listByLatest/listByCollection 改动态 SQL）；前端 `loadMedia()` recent/collection 分支拼接筛选参数。format/subcategory 仍客户端兜底。生效需重建镜像 `docker compose build app`（app.js 已同步 target）。

### [#2] 「最近观看」下收藏夹筛选无效（同 #1 根因：recent 分支忽略 mediaFilter）
- **日期**：2026-08-06
- **模块**：媒体管理 / 收藏夹
- **严重程度**：🟧 一般
- **复现步骤**：
  1. 切到「最近观看」tab
  2. 从收藏夹下拉选中某收藏夹
  3. 媒体列表未按收藏夹过滤，仍显示全部最近观看媒体
- **期望行为**：只显示所选收藏夹里的媒体
- **实际行为**：筛选被静默忽略
- **根因（已读码）**：`loadMedia()`（app.js:956）`if (mediaFilter.collectionId && mediaMode !== 'recent')`——recent 模式下收藏夹分支被跳过，url 恒为 `/api/media/recent`。
- **状态**：🟩 已修复（2026-08-06，与 #1 一并修复）
- **备注**：修复方案同 #1（后端接口支持筛选参数 + 前端拼接）。

### [#3] 批量删除勾选选不中（checkbox 冒泡被 card click 二次 toggle）
- **日期**：2026-08-06
- **模块**：媒体管理
- **严重程度**：🟧 一般
- **复现步骤**：
  1. 工具栏点「批量删除」进入批量模式
  2. 点卡片上的勾选框
  3. 勾选框闪一下随即取消，无法选中
- **期望行为**：点勾选框稳定选中，卡片高亮
- **实际行为**：选中瞬间被取消
- **根因（已读码）**：勾选框嵌在卡片内，其 click 冒泡到 card 的批量模式 handler（`cb.checked = !cb.checked` 再 toggle 一次），与勾选框自身 toggle 抵消 → 选不中。
- **状态**：🟩 已修复（`media-batch-cb` 加 `click stopPropagation`）
- **备注**：点卡片其他区域仍可切换勾选（批量模式），不受影响。
