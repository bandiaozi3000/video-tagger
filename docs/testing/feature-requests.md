# 需求清单

### [#1] 媒体删除仅限详情页——媒体栏（媒体网格）下需直接删除入口，并支持批量删除
- **日期**：2026-08-06
- **模块**：媒体管理
- **优先级**：中
- **需求描述**：在媒体栏（媒体网格列表）下直接删除媒体，最好支持多选批量删除，不必逐个进详情页。
- **现状（已读码验证）**：媒体网格卡片（`renderMediaGrid` app.js:1052）无删除按钮，点击仅进详情页；删除按钮只在详情页（`deleteMedia()` app.js:1705 / `detail-delete` 行 1922）；后端仅单删 `DELETE /api/media/{id}`（MediaController.java:74），无批量端点。
- **状态**：🟩 已完成（2026-08-06，代码完成+单测通过；待实测确认+提交）
- **备注**：交互形态采用「卡片 hover 删除按钮单删 + 工具栏批量删除模式（勾选卡片批量删）」；后端新增 `DELETE /api/media?ids=...` 批量端点。

### [#2] 收藏夹创建入口仅在媒体详情页——媒体栏等位置需添加入口
- **日期**：2026-08-06
- **模块**：收藏夹
- **优先级**：低
- **需求描述**：除媒体详情页外，在媒体栏（媒体管理页）或其他入口提供创建收藏夹的能力。
- **现状（已读码验证）**：`renderDetailCollections`（app.js:1032）里「+ 新建收藏夹」输入框只在媒体详情页渲染；媒体栏收藏夹下拉（`filter-collection`）只有选择，无新建入口。后端 `POST /api/collections` 已支持创建。
- **状态**：🟩 已完成（2026-08-06，代码完成+单测通过；待实测确认+提交）
- **备注**：媒体栏收藏夹下拉旁新增「＋ 新建收藏夹」按钮，用项目风格 modal（非 prompt）输入名称 → POST → 选中新收藏夹刷新列表。

### [#3] 季/集号手动编辑入口 + 识别不到默认第1季第1集
- **日期**：2026-08-06
- **模块**：媒体管理 / 打标
- **优先级**：中
- **需求描述**：
  1. 提供季/集号**手动编辑入口**（集详情页内联编辑或弹窗，`PUT /api/episodes/{id}` 扩展 `season`/`episodeNo` 字段）。
  2. 打标识别不到季/集号时，**默认 season=1、episodeNo=1**（而非存 null）。
- **现状（已读码验证）**：`PUT /api/episodes/{id}` 仅更新备注（`EpisodeUpdateRequest` 只有 note 字段，EpisodeController.java:47）；`ensureEpisode`（ClipService.java:259-260）季/集解析不到直接存 null，前端显示「本集」；`IFNULL(season,0)` 排序。
- **状态**：🟩 已完成（2026-08-06，代码完成+单测通过；待实测确认+提交）
- **备注**：`PUT /api/episodes/{id}` 扩展 season/episodeNo（传 null 不改）；集详情页头部「编辑季/集」内联编辑。
- **方案变更（2026-08-06 用户实测后）**：原「识别不到默认 S1E1」**改为**「识别不到保持 null → 前端『未识别季/集』分组单独展示 + 高亮提示编辑，编辑后归入对应季」。`ensureEpisode` 已回退（不写默认 1/1）。**新增**：媒体详情页集列表按季分组展示（第N季组头 + 集行，季为空入未识别组）。
