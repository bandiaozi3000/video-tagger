待你拍板的点

1. 方向本身：押「银幕·章节」（深黑影院 + 满屏出血 + 大字排版）。备选是「杂志编排」（亮纸底 + 巨字拼贴）与「星云玻璃」（沿用现有星空母题强化）。

2. 开屏主推：复用现有 openingIds 当"主推"语义（空 = 取前 1 部）。开屏是否要保留"整批调性"的封面墙作为背景？

3. 片段画面：原比例居中（不裁画面，两侧留黑）+ 模糊铺底；还是 object-fit:cover 满屏裁切（更沉浸但要切掉内容）？我押前者。

4. 字体：大标题用宋体/思源宋体（serif）以拉开与站点的距离。渲染机若无此字体需打包字体文件（staticFile + @font-face），要不要接受这个成本？

5. 信息取舍：单媒体段现在能拿到的只有 标题 / 年份 / 季 / 简介(=你手写那句话) / 标签 / 片段数（元数据未接线）。信息稀疏时是否允许"大片留白"？

6. 静音可读：片段段的字幕条/标签是我按"静音观看"设计的，字号偏大（26px / 22px）。群里发的场景确认吗？

7. 每段时长：开屏 6s、单媒体 6s、片段按素材长度（12.3s）、结尾 5s —— 节奏对不对？

8. 是否保留"资料推荐 / 片段推荐"角标与"PICK NO.xx"这类英文小标（本稿最小化保留）。
