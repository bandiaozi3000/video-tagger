# Video Tagger 集/片段详情页设计总结

- 日期：2026-08-03
- 状态：grilling 确认，待实施（分两期）
- 关联文档：实施计划 `plans/2026-08-03-video-tagger-detail-pages-phase1~2-plan.md`
- 前情：v0.4 帧封面已交付（片段截帧/集封面/番剧兜底）；本次解决「片段卡片大图顶置样式异常」并补详情页。

## 1. 背景与定位

v0.4 给片段加了截帧封面后，列表卡片是**全宽 16:9 大图顶置**布局——卡片被图片撑得很高、打开看样式怪异。用户希望：

- 列表改为**左侧缩略图**横排（小图在左、信息在右），视觉清爽。
- 新增**集详情页 + 片段详情页**，点卡片打开看完整情况；两页逻辑一致（对称设计）。
- 详情页之间可链式跳转（片段 → 所属集 → 所属番剧），返回栈要正确。

定位延续「工具 + 练手」：纯展示增强，不引入新数据模型与后端复杂查询。

## 2. 已确认决策（grilling 拍板）

| # | 决策点 | 结论 |
|---|---|---|
| 1 | 点击行为 | **点卡片进详情页**；跳回原视频移到详情页「去原视频」按钮。**时间线轴上的标记小圆点保持直接跳转**（精准 seek 控件，与卡片不同）。 |
| 2 | 片段详情区块 | 大图 + 元信息 + **集/番剧导航** + **操作入口**（去原视频/编辑/删除/相似）+ **同集其他片段** + **相似片段**，全做。 |
| 3 | 集详情 vs 时间线 | 集详情展示信息与片段列表，**保留「时间线」按钮**跳现有时间线视图（不吸收）。 |
| 4 | 左缩略图范围 | **全部片段卡片**统一横排（搜索/时间线/相似弹窗/集详情内片段/片段详情内同集片段）。 |

## 3. 页面结构

### 3.1 片段详情页 `view-clip-detail`
```
← 返回（视图历史栈）
┌ 大图封面（截帧）┐
标题 · 时间戳 · 标签 · 备注
所属集：第X集 →（点进集详情）｜所属番剧：《XXX》→（点进番剧详情）
[去原视频] [编辑] [删除] [相似]
── 同集其他片段 ──（左缩略图列表，可互相跳转）
── 相似片段 ──（复用 /api/search/similar）
```

### 3.2 集详情页 `view-episode-detail`
```
← 返回（视图历史栈）
┌ 集封面 ┐  标题 · S1-Ep3 · 片段数 · 最近标记
所属番剧：《XXX》→（点进番剧详情）
集标签（可删）+ 添加
[打标签] [设封面] [时间线] [去原视频]
── 该集片段 ──（左缩略图列表，点进片段详情）
```

## 4. API（后端小改动）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/clips/{id}` | 片段详情（完整 Clip：含 videoFp / episodeId / coverPath / tag / note）。 |
| GET | `/api/episodes/{id}` | 集详情（EpisodeDetail：解析封面 + 集级标签 + clipCount + latestAt + videoFp）。 |

同集片段复用 `GET /api/videos/{fp}/clips`（Clip 与 EpisodeDetail 均带 videoFp，前端据此取该集片段）；番剧名复用 `GET /api/anime/{id}`。

## 5. 前端结构与导航

- 新增 `view-clip-detail`、`view-episode-detail` 两个视图（沿用 `anime-detail` 单页模式）。
- **视图历史栈** `viewHistory: string[]`：进详情页时 push 当前活动视图名；返回时 pop 并按名恢复渲染（`restoreView` 分发到 search/anime/timeline/anime-detail/episode-detail/clip-detail 各自的加载器）。
- 卡片点击去向：片段卡片 → 片段详情；集卡片 → 集详情；番剧卡片 → 番剧详情（现状）。
- 相似弹窗内点卡片进详情页，先进栈再关弹窗，返回能回到原视图。

## 6. 列表改版

`appendClipCard` 改为横排：
```
┌─ 128px 16:9 缩略图 ─┐ 标题
│                     │ 时间戳 · 标签
└─────────────────────┘ [相似] [编辑] [删除]
```
- 无封面时省略缩略图槽位，布局不塌。
- 一处改动覆盖搜索 / 时间线 / 相似弹窗 / 集详情内片段 / 片段详情内同集片段。

## 7. 风险与注意点

1. **导航栈正确性**：详情页链式跳转（片段→集→番剧、片段→同集片段→…）返回要逐层还原；`restoreView` 必须对每类视图做正确的重新加载（含 currentQuery/currentAnime/currentVideo/currentEpisode/currentClip 状态）。
2. **点击行为变更**：所有片段卡片从「直接跳转」改为「进详情」，详情页要放醒目的「去原视频」按钮，避免核心回看流程变繁琐。
3. **相似弹窗进详情**：进详情前关弹窗、入栈，否则弹窗残留覆盖详情。
4. **编辑/删除刷新**：详情页内编辑/删除后要刷新当前详情视图（扩展 `refreshCurrentView`）。
5. 时间线标记小圆点维持直接跳转，与卡片行为不同是有意为之（精准 seek）。

## 8. 范围界定（YAGNI）

本期不做：详情页内嵌视频播放器、评论/评分、多图片画廊、集详情吸收时间线视图。

## 9. 分两期规划

- **Phase 1 · 列表改版 + 地基**：左缩略图卡片 + 两个 GET 端点 + 两个视图骨架 + 视图历史栈。
- **Phase 2 · 详情页交互**：片段详情全区块（导航/操作/同集/相似）+ 集详情交互（标签/设封面/时间线/去原视频）+ 点击行为全局切换。
