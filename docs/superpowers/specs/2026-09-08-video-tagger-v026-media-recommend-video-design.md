# v0.26 媒体级模板化推荐视频设计

- **日期**：2026-09-08
- **版本**：v0.26.0
- **状态**：方案调整为 HTML 单媒体模板，已完成独立视觉原型，业务接入待实施
- **配套计划**：`docs/superpowers/plans/2026-09-08-video-tagger-v026-media-recommend-video-plan.md`
- **原型**：`docs/design/2026-09-08-v026-single-media-recommend-template.html`

## 1. 重新定位

Video Tagger 不做 Premiere/DaVinci 的替代品，也不把当前高光工作台包装成“高级剪辑器”。v0.26 的主产品是：

> **用户选择内容，系统用模板快速生成一条质量稳定、可直接分享的单媒体推荐视频。**

用户已经通过 Clip、标签和备注表达了“推荐什么”；系统负责作品介绍、场景编排、动画、素材准备、预览和导出。专业软件继续承担多轨剪辑、调色、字幕、特效和最终母版。

## 2. 产品结构

```text
媒体详情
  → 制作推荐视频
  → 单媒体推荐模板
  → 用户勾选 Clip
  → 生成 HTML 预览
  → 确认后录制 MP4 / 下载 HTML

高级编辑
  → 当前高光工作台
  → 调整入出点、排序、剧透、音量和素材来源
```

不再把“单媒体推荐”和“高光混剪”作为两个并列的用户产品。高光项目继续作为选片、素材和高级配置的内部模型/入口。

## 3. 渲染分层

```text
Media / Clip / VideoAsset
        ↓
Recommendation ScenePlan
        ↓
┌────────────────┬──────────────────┬──────────────────┐
│ HTML Renderer   │ FFmpeg Utilities  │ NLE Exporter     │
│ 视觉/预览/分享   │ 裁剪/转码/封装     │ FCPXML/OTIO 后续 │
└────────────────┴──────────────────┴──────────────────┘
```

### HTML Renderer

负责片头、简介、章节、片段标题、封面墙、动画、BGM 展示和浏览器预览；正式视频使用同一模板的录制模式，避免预览和成片视觉分叉。

### FFmpeg

只负责素材裁剪、画幅标准化、音频补齐、必要的混音/封装和最终文件校验，不再承担复杂推荐卡片的主要视觉设计。

### ScenePlan

ScenePlan 是渲染输入的稳定抽象，不让某个模板或某个剪辑软件格式成为业务主模型：

```json
{
  "scope": "SINGLE_MEDIA",
  "media": { "id": 39, "title": "...", "year": 2015, "tags": [] },
  "scenes": [
    { "type": "opening", "duration": 6 },
    { "type": "chapter", "episodeNo": 3 },
    { "type": "clip", "clipId": 123, "in": 42.5, "out": 58.2 },
    { "type": "ending", "duration": 5 }
  ]
}
```

## 4. 单媒体模板结构

### 4.1 作品档案片头

- 媒体封面；
- 标题；
- 首播年份/季度；
- 外部简介摘要；
- 前几项媒体标签；
- Clip 数量和涉及集数。

封面回退顺序：

```text
本地媒体封面
→ 代表性 Clip 帧
→ 可用外部缓存封面
→ 纯色/纹理背景
```

个人备注、收藏状态和管理字段默认不进入分享视频。

### 4.2 推荐导语

显示本次推荐范围，例如：

```text
用户选择的 N 个片段 · 涉及 M 集
```

可选一段短文案，不要求用户重新填写作品标题。

### 4.3 片段放映

- 用户勾选的 Clip 全部保留；
- 首次按集号和片段时间排序；
- 用户拖拽后保留自定义顺序；
- 片段开头短暂显示“第 N 集 · Clip 标题”；
- 信息层约 2~3 秒后淡出；
- 正片主体保持画面干净。

### 4.4 章节

默认规则：

```text
片段少或只有一集 → 不显示章节
片段较多且跨集 → 显示章节
```

提供“自动章节 / 始终显示 / 关闭”控制。

### 4.5 推荐回顾墙

- 媒体标题；
- 本次纳入片段数量；
- 涉及集数；
- Clip 封面或代表画面；
- 简短收束文案。

## 5. 用户控制

### 默认区

- Clip 勾选和排序；
- 生成预览；
- FULL / SAFE；
- BGM（默认无）；
- 片头开关；
- 片尾开关；
- 片段标题开关；
- 集号开关；
- 章节策略；
- 预计时长；
- 默认 MP4 / 1080P。

### 高级区

- Clip 入点/出点；
- 原声音量；
- 转场细节；
- 画质和 WEBM；
- 片头/片尾细节；
- 本地源、上传和直链处理；
- 后续专业剪辑工程导出。

不开放原始 FFmpeg 参数、任意布局坐标、关键帧、多轨时间线和专业调色控制。

## 6. 预览、缺源与导出

### 预览

用户完成选片后点击“生成预览”才开始处理。预览采用与正式录制相同的 ScenePlan 和 HTML 模板，降低分辨率/编码成本但不改变叙事结构。

### 缺源

```text
已选 8 段
→ 6 段可用，2 段缺失
→ 生成 6 段预览
→ 显示 2 段缺失的片段、集和原因
```

用户可以：

- 重新准备；
- 上传；
- 移除；
- 导出当前可用版；
- 补齐素材后重新生成完整预览。

部分导出必须写入快照和导出记录，不得静默跳过。

### 输出

默认：

```text
MP4 / 1080P / 无 BGM
```

同时可以下载自包含 HTML 或 HTML + 本地媒体资源包。专业用户后续可导出 FCPXML/OTIO，交给 Premiere/DaVinci 精修。

## 7. 数据与复用边界

复用：

- `HighlightProject` / `HighlightProjectItem` 作为单媒体推荐草稿；
- `MaterializationService` / `HighlightSourceService` 作为素材求值和准备；
- `RecommendService` 的媒体资料、标签、封面和 Clip 数据；
- `recommend-clip.html` 的资源引用、BGM、浏览器录制和自包含 HTML 经验；
- 现有导出快照、异步任务和受控路径。

不新增：

- 第二套 Clip 选择表；
- 第二套本地资产模型；
- 完整专业剪辑器；
- 默认音乐资源库。

## 8. 当前原型

`docs/design/2026-09-08-v026-single-media-recommend-template.html` 是独立视觉原型，已验证：

- 作品档案片头；
- 本地封面；
- 简介、标签和统计；
- Clip 播放区；
- Clip 切换；
- 集号/标题提示；
- 章节提示；
- 推荐回顾墙；
- 播放控制和滚动导航。

原型使用仓库已有演示素材，不接入业务接口，不替代正式模板。
