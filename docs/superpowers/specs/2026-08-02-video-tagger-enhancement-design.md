# Video Tagger 功能深化 · 产品设计总结（v1）

- 日期：2026-08-02
- 状态：讨论总结，待实施
- 关联文档：初版设计 `2026-07-20-video-tagger-design.md` / 初版计划 `2026-07-20-video-tagger-plan.md`

## 1. 背景与定位

初版已实现「网页视频片段打标签 + 混合语义搜索 + 一键回看」的**最小闭环**，但只是"能跑"的程度。本次目标：**让功能更完整、更像一个真正可用的个人工具**。

定位已确认：**工具与练手两者兼顾**——既要在日常使用中顺手、可靠、不丢数据，又保持 Java / 架构探索的价值（Milvus 等有意为之的选型保留）。

## 2. 现状盘点（已实现）

| 模块 | 能力 |
|---|---|
| 后端 | `POST /api/clips` 保存；`GET /api/search` 混合检索（MySQL ngram 全文 + Milvus 向量 + RRF 融合）；`POST /api/jump` / `GET /api/jump/pending` 回看队列 |
| 扩展（MV3） | `Alt+S` 抓取 `<video>` + Shadow DOM 打标浮层；保存走 background POST；页面加载后轮询自动 seek |
| Web UI | 深色卡片风搜索页（静态 HTML/CSS/JS，后端托管） |
| 基础设施 | Docker Compose 一键部署（mysql / etcd / minio / milvus / attu / app） |

## 3. 现状诊断

### 3.1 P0 炸弹（不修则后续功能失去地基）

1. **Milvus 冷启动竞态 → 语义搜索永久哑火**
   `docker-compose.yml` 对 `milvus` 用 `condition: service_started`（无健康检查）；`MilvusVectorStore.init()` 仅重试 3 次 × 3 秒后 `enabled=false`。Milvus 冷启动需 30~90s，**冷启动后语义搜索几乎必然关闭且永不重连**，即使 API key 配置正确。
2. **3 秒去重静默吞数据**
   `ClipService.save` 同一 URL 3 秒内第二次保存直接 `deduped=true` 丢弃；扩展端不消费该标记，用户看到"已保存"实则数据被吞。
3. **密钥与暴露面**
   `application.yml` 将真实 API key 硬编码为兜底默认值（`${EMBEDDING_API_KEY:sk-...}`），未进 git 但随时可能被提交；`server` 未绑 `127.0.0.1`，服务暴露局域网。**正解**：key 只放 `.env`（已 gitignore），yml 默认值清空，绑定回环地址。

### 3.2 分层优化清单

| 层级 | 主题 | 要点 |
|---|---|---|
| 🟠 数据闭环 | 编辑 / 删除 / 追加标签 | 全后端只有 3 个接口，标签只进不出；编辑触发重嵌入；删除同步清 Milvus |
| 🟠 数据闭环 | 导出 / 导入 | 个人标签库备份与迁移 |
| 🟡 日常链路 | 打标效率 | 标签历史 / 补全 / 快捷标签位 / 连续打标 |
| 🟡 日常链路 | 浏览模式 | 最近标签 / 按片名分组 / 筛选 + 分页 |
| 🟡 日常链路 | 跳转可靠性 | 原生 `?t=` 覆盖主力站点；未知站点用 `#vt=` hash；轮询窗口拉长 |
| 🟢 工程化 | 错误体 / 校验 / 文档 / 测试 | 让"像那么回事" |

## 4. 产品价值循环（四拍）

```
看视频 → 捕获片段 → 找回片段 → 无缝跳回
 watch    capture      recall     re-engage
```

功能丰富点全部落在某一拍或两拍之间的连接上。另有两个当前缺失的维度：**资产化**（劳动成果可视化、可带出）与**场景扩展**（不看网页也能记）。

## 5. 功能丰富方向（六段）

### 5.1 捕获段：从"能打标"到"秒级打标"
- 快捷标签位（`Ctrl+Shift+1~9`，勿用 `Alt+数字`——浏览器默认切标签页冲突）
- 连续打标模式（保存后浮层不关、tag 预填、时间戳实时跟随）
- 标签补全 + 最近使用
- 重复片段提示（同片段已存 → 追加标签而非新建）
- 帧截图辅助记忆（可选，后期）

### 5.2 回顾段：把"一筐标签"变成"一张地图"
- **视频时间线视图**：点进一个视频，标记点沿时间轴排开，点击即跳
- **剧集 / 系列分组**：按标题前缀自动聚类，追剧主干
- **标签管理页**：标签按次数排序、点击查看、支持重命名 / 合并迁移

### 5.3 召回段：从"搜得到"到"找得到顺手的"
- **相似片段推荐**：同标签优先 + 向量近邻，剪片找素材的"先找到一个，再要一筐"
- 语义增强：`title` 纳入嵌入文本
- 筛选维度：站点 / 时间范围 / 系列 / 标签
- 搜索历史

### 5.4 再观看段：从"跳得过去"到"无缝"
- 跳转后微调并回写（闭环）
- 多标记点预览选择
- 记录"上次看到哪"

### 5.5 资产化段：让劳动成果看得见、带得走
- 统计面板（总量 / Top 标签 / 站点分布 / 近 7·30 天趋势）
- 导出为观后笔记（Markdown / JSON，备份 + 分享 + 整理）
- 随机回顾卡片

### 5.6 场景扩展段：跳出"开着网页才能用"
- 剪贴板打标（复制链接 → Web UI 填时间戳与标签）
- 局域网手机只读浏览
- 撤销 / 回收站（误删恢复）

## 6. 首期三张牌（核心决策）

> 排期建议：**牌二 → 牌一 → 牌三**。先解决"存得不爽"，再解决"看得见"，最后"逛得爽"。

### 🃏 牌一：视频时间线视图

- **入口两条路**：① 搜索结果卡片点进；② 新增"视频列表"页（按片名聚合）下钻。
- **时间线两段式**：上段横轴时间线（标记点按秒排布，点击即跳，回答"这集我在哪几段打过卡"）；下段按时间排序的标记点列表（完整信息）。
- **已拍板决策**：
  1. 时间轴按"秒"排布，**不依赖 `video_duration`**（两端取 min/max），时机未到不加字段；
  2. **"同一个视频"按归一化 URL（`video_fp`）聚合**——洗掉 tracking 参数（pn / from / spm / list 等），保留分 P 参数（p / index）——这是聚合正确性的命根子；
  3. 分 P 视频标记点显示 P 号（`P2 · 08:40`）；
  4. 空态引导"去看片按 Alt+S"。

### 🃏 牌二：连续打标 + 快捷标签位

- **快捷标签位**：options 页配置 9 个槽位绑定标签；按下后抓当前片段 + 预填标签浮层，回车即存。
- **连续打标**：保存后浮层不关、tag 保持、时间戳跟随播放进度实时刷新（0.5s 一跟）；显示"本次已连续保存 N 条"。
- **已拍板决策**：
  1. ⚠️ 快捷键用 `Ctrl+Shift+1~9` 而非 `Alt+数字`（浏览器切标签页冲突），全量可自定义；
  2. 快捷标签位**默认弹浮层预填，不做静默直存**（防误触），静默存做可选配置；
  3. **连续模式默认关、手动开**（防看片走神存一串错点）；
  4. **重复片段 ±10s 内已存 → 默认"追加标签到那条"**（同画面两行迟早是脏数据），同时给"仍然新增"选项；
  5. 标签补全走**后端聚合查询**（`GROUP BY tag` 带次数），先不建标签表。

### 🃏 牌三：相似片段推荐 + 统计面板

- **相似推荐**：同标签优先 + 向量近邻补充（clip 自身向量 ANN 查询，排除自身）。
- **统计面板**：总片段 / 视频 / 标签数；Top10 标签（可点击进搜索）；站点分布；近 7·30 天趋势。
- **已拍板决策**：
  1. 相似排序**同标签优先**，向量近邻当补充（个人千级库同标签更靠谱）；
  2. 统计**不引图表库**，原生 SVG 画柱状 / 折线，保持深色卡片风（守住"不引前端框架"的规矩）；
  3. 统计全部走**聚合查询，不加表**。

## 7. 前置依赖（实施时须先于牌一起）

- **P0 三颗雷**：Milvus 冷启动竞态、3 秒去重吞数据、密钥与暴露面。
- **编辑 / 删除 / 追加标签 API**：牌二"重复片段→追加标签"依赖它，须先行。
- **URL 归一化（`video_fp`）**：牌一聚合的命根，保存时即计算落库（需 schema 迁移）。
