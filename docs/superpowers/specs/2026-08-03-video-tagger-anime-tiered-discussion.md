# Video Tagger 番剧三层打标 · 需求讨论记录（grilling 会话）

- 日期：2026-08-03
- 状态：讨论完成，全部决策已确认
- 关联文档：产品设计总账 `2026-08-03-video-tagger-anime-tiered-design.md` / 三期执行计划 `plans/2026-08-03-video-tagger-anime-tiered-phase1~3-plan.md`

## 1. 讨论背景

用户原始需求一句话：「界面类似目前的番剧网站，记录最近看番或电影，能对此进行分类；打标分两个维度——对番剧打标 + 对番剧具体集数内容视频片段打标。」

经由 grilling（拷问式追问）会话逐层拆解，最终收敛为一套 **「番剧 → 集(含季) → 片段」三层打标结构** 与完整的决策总账。本文件记录每一轮追问、用户拍板与关键影响；决策本身见总账文档。

## 2. 逐轮讨论记录

### 2.1 番剧实体从哪来（首要地基）

**追问点**：现系统只有 `clips`（片段）一张业务表，`video_fp` 保留分 P 参数，语义上 ≈ "集"级标识——**不存在番剧实体**。"多集归一部番"无法从 URL 得知（B 站普通视频只有 BV 号、每集不同；YouTube 无番剧概念）。

**决策**：引入番剧实体；识别 = **标题前缀 + 正则**（打标主链路，纯本地快速）+ **LLM 后台归组修正**（可开关）+ **手工确认兜底**；不同季归同一部番；提供 **改名 / 合并** 功能兜底。

**关键影响**：打标主链路不碰大模型，保持秒级手感；番剧归属可能"暂时不准"，由后台与手工逐步纠正。

### 2.2 标题自动识别的正确性预期

**追问点**：以《葬送的芙莉莲》真实标题为例——B 站分篇标题「魔法考试篇 / 一级魔法使篇」、字幕组站 `Frieren Season2 Ep01`、网盘「芙莉莲 第二季 第1话」前缀完全不同；甚至存在标题不含番剧名的情况；《Fate》系列同前缀不同作品边界模糊。

**决策**：前缀与 LLM 仅是初步手段，**最终兜底靠手工确认**（见 2.6）。

### 2.3 电影与层级

**决策**：**电影 = 单集番剧**，用 `type` 字段区分；三层结构 = 番剧 → 集(含季) → 片段，**三层均可打标**。

### 2.4 最近观看与追番状态

**决策**：**打过标记即算最近观看**（不额外录入）；追番状态（想看/在看/看完/搁置/弃番）**手动录入**，为番剧表单选字段。

### 2.5 分类体系（三件套）

**追问点**：追番状态（单选）与收藏夹（多对多）**数据模型不通用**；分类 vs 标签边界不清。

**决策**：分类与标签**分开**；分类**只当筛选器**；`type` 内容类型收敛为 `ANIME / MOVIE` 两级（细分用标签表达）；收藏夹用 `collection` + `anime_collection` 关联表，**本期就做**。

### 2.6 手工确认的交互位置

**追问点**：手工确认在"打标时浮层"还是"Web UI 列表"？浮层确认会拖慢打标，违背"秒级不打断"。

**决策**：**A 做轻 + B 做全** —— 打标浮层仅一行小字展示「识别到：番剧 · 第X集」（纯展示、可点开改、**不阻塞保存**）；番剧列表保留 **「待确认」标记**，闲时批量审核。

### 2.7 集级打标入口

**追问点**：集级标签无时间戳，扩展浮层天然是片段级；"给整集打标"何时发生？

**决策**：首版集级打标**走 Web UI**（番剧详情页）；「看完自动弹」记**待办**后续优化。

### 2.8 搜索对象与向量化

**追问点**：此前定的搜索维度"番剧 / 片段"与三层结构矛盾——**集被弄丢了**；三层向量化涉及 Milvus 主键冲突。

**决策**：**集是独立搜索对象**，搜索维度 = 番剧 / 集 / 片段 / 混合；**三层全向量化**（Milvus 是项目接触 RAG 的练手核心）。

### 2.9 封面获取与存储

**追问点**：B 站图片防盗链，外链展示会裂图；存储位置待选。

**决策**：扩展打标时携带 `og:image` → 后端**异步下载落盘** + Spring 静态资源映射（`/covers/**`）；Web UI 支持手动上传 / 粘贴 URL 兜底；**不上 minio**（个人量级，本地目录足够）。

### 2.10 评分

**决策**：`rating` 字段**手动录入**（十分制），不做社区聚合。

## 3. 被否决 / 收敛的选项

| 选项 | 结果 | 理由 |
|---|---|---|
| 大模型实时识别番剧归属 | 否决 | 拖慢打标主链路 |
| `type` 细分 动画/真人/纪录片… | 收敛为 ANIME/MOVIE | 枚举越细迁移越痛，细分用标签表达 |
| 集标签并进番剧/片段搜索 | 否决 | 集独立成搜索对象，定位更精准 |
| 封面存 minio | 否决 | 个人量级，本地落盘足够 |
| 看完自动弹（本期） | 暂缓，记待办 | 主动打断违背"不打断看片"原则 |
