### 关键 gotcha（overview 显示 bug，用户实测发现）
1. **数字/字符串严格比较**：`showView(g)` 里 `v===g2`，`2024 === "2024"` 恒 false → group-view 的 `.show` 加不上，切组后组视图不显示。修复：`String(v)===g2`。
2. **IntersectionObserver 时序**：总览/组内卡片 opacity:0 依赖 IO 触发 `in-view`，切视图后 IO 触发不可靠 → 卡片一直透明。修复：`showView` 切视图时**主动给当前视图卡片加 `in-view`**（不赌 IO）。
3. **静态资源复制**：前端 index.html/app.css/app.js 改动后 target/classes/static 不会自动同步（mvn compile 增量不复制）——手动 `cp` 到 target/classes/static + 删 target/classes/templates/recommend.html 残留。

## v0.18 推荐导出细化：BGM 多曲 / 副标题 / 封面可调（同日）

**需求**（用户 6 点）：①BGM 多选、顺序连续 + 快结束提示下一首；②开局自选番剧（开场显示=勾选数，步骤1补「开场将显示 N 个封面」提示）；③副主题可配置（存在显示/为空隐藏）；④封面大小可调（小/中/大，默认中=比原大 15%）；⑤record 模式去右上角自动导览徽标；⑥BGM 条显示当前曲名/进度/时间。

**实现**：
- 后端：`RecommendExportRequest` 加 `bgmTracks`（[{name,base64}]）/`subtitle`/`coverSize`；`RecommendService` 新全参 `buildHtml` 注入 `__SUBTITLE__`（空→隐藏）/`__COVER_SIZE__`（sm/md/lg）/`__BGM_TRACKS__`（JSON），旧单曲字段兼容映射。`RecommendVideoService.render` 多曲 → ffmpeg filter_complex concat（统一 44100 stereo aac）拼单文件 → 现有 `--bgm` 混音。
- 模板三套：hero-plate 副题 `__SUBTITLE__`（空 JS 隐藏）；开场卡片 `COVER_COEF={sm:.85,md:1.15,lg:1.4}`；BGM 多曲播放队列（顺序连续 + 剩余<4s 提示「即将播放：下一首」金色高亮 + 当前曲名/进度）；`beginAutoGuide` 里 `autoBadge.hidden = IS_RECORD`。
- 前端：步骤2 副标题输入 + BGM `multiple` 多选列表（单项移除）+ 预览弹窗「封面大小」下拉（改选重生成）；三处导出请求带 subtitle/coverSize/bgmTracks；步骤1计数补「开场将显示 N 个封面」。

**验证**：单测全过；`validate-templates.js` 扩展用例（多曲BGM+record+大封面 scale 1.4、副题空隐藏、record 徽标隐藏、分组渲染）全 ✓ 零 JS 错误。版本 0.18.0。
