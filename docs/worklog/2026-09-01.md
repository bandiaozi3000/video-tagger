## v0.23 独立播放窗口与 Animeko 查询对照

- 对照 Animeko 6.0.0 官方源码确认：其 Selector 使用主标题搜索、全部作品名过滤、特殊字符归一化和模糊匹配；Web 数据源共享 Cookie/UA 身份，播放端使用 MPV/VLC，因此不会遇到普通浏览器相同的 CORS 与编解码限制。
- 新增独立 `/player.html`：Web 通过用户点击打开 popup，Electron 对同源播放器地址创建 1500×900 子窗口；采用左侧视频、右侧来源/解析状态、下方 Clip Dock，视觉仍复用当前网站风格。
- 快捷查询加入媒体别名、多关键词重试、URL 去重、标题相似度排序、纯数字集号识别，并将单 Provider 时限从 12 秒调整为 20 秒。
- 新增会话绑定媒体中继，仅允许当前快捷播放候选访问，转发合法 Range、来源页 Referer 和浏览器型 User-Agent，逐跳校验公开重定向；不转发 Cookie、Authorization 或任意自定义请求头。
- 新增标题归一化、别名重试、数字集号和中继 Range/Referer 测试；相关定向 Maven 测试、Java 编译、四个 JavaScript 语法检查和 diff 检查通过。
- 真实失败线路仍需逐条分类；HLS/DASH、MKV、登录/验证码和 DRM 未因本次中继自动获得支持。

## v0.23 精确匹配与播放器重构

- 对齐 Animeko 的查询思想：查询对象新增作品/集外部 ID、全部集标题、季度集号和系列集号；快捷播放从 `external_work` / `external_episode` 读取已同步关联。
- 候选现在按“外部 ID → 作品标题 → 集号/集标题”分层匹配；作品标题不匹配或集号冲突直接排除，不再允许仅凭相同集号误选相似番剧；候选返回匹配等级和原因。
- Web Selector 在详情抓取前过滤低置信搜索结果，详情页标题写入脱敏快照参与二次校验。
- 播放器改为沉浸式视频舞台、底部可拖拽时间轴、I/O/M 标记、来源抽屉、Clip 编辑、已保存 Clip 快速定位/循环回看和折叠解析诊断；错误提示区分网络、编码和不支持的 HLS/DASH/MKV/DRM 等情况。
- 明确取舍：本项目继续服务“播放后维护标签和 Clip”，不引入弹幕、评论、共同观看、推荐流、持久播放历史或原生 MPV。
