## v0.8 媒体/集层备注 + 搜索增强（grilling → spec → 实现）

**需求缘起**：用户「当前只是新增标签，先添加备注供后面更好的搜索」——但排查发现片段级 `clips.note` 已全链路存在（扩展弹层输入 → 后端 → 关键词+向量 → Web UI）。grilling 定位真正缺口在**媒体/集层**。

### 拍板决策（/grill-me 两轮）
1. **媒体/集层备注**（片段已有一级不重做）。
2. **搜索全字段高亮**（标题/备注/标签命中词都高亮，`<mark>`）。
3. **编辑入口**：媒体备注放新建/编辑弹窗 + 详情页展示；集备注集详情页内联编辑；扩展弹层不动。
4. **三件呈现增强**：搜索按媒体聚合（默认开）+ 打标时间范围筛选 + 结果角标（格式/子分类/站点）。
5. **新字段维度**（使用状态/来源/人物/时长）本期不做。
6. **检索质量优化分两期**：v0.8 只做备注+呈现增强；上下文增强/同义词扩展/MySQL BM25/评测集 归 **v0.9**。
