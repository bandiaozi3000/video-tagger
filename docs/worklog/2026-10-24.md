### 「← 返回媒体」点了没反应（小改动，无规格/计划）

**用户报告**：媒体详情页的「返回媒体」按钮不生效。

#### 一、根因（实测，非推断）

`backend/src/main/resources/static/app.js` 的工作副本**被截断**：文件末尾停在半截标识符 `refreshExportBa`（无换行、无后续代码）。
对照 `git show HEAD:...` 可见丢失的正是最后 8 行：

```js
refreshExportBadge();
setInterval(refreshExportBadge, 15000);
if (RECOMMEND_DESKTOP_MODE) { ... 素材库 ... }
startRouting();          // ← 监听 popstate/hashchange + 应用初始路由
```

`startRouting()` 没跑 ⇒ `popstate`/`hashchange` 两个监听器**从未注册**。而 `goBack()` 是 `history.back()`，
按钮本身点得动、URL 也真的退回了 `#/media`，但没人接事件 ⇒ 视图停在详情页不动。

同理失效的还有：F5/手改 hash 不进对应视图、状态栏「导出任务 N 个」不再轮询。

#### 二、探针证据（`scripts/probe-browser.mjs` 改 STEP 路径，headless Chrome + CDP）

修复前（点媒体卡 → 详情 → 点返回）：

```
afterOpenDetail  hash=#/media/6224 view=media-detail mediaDetailHidden=false
afterBackClick   hash=#/media      view=media-detail mediaDetailHidden=false   ← hash 退了，视图没退
events: ReferenceError: refreshExportBa is not defined  at app.js:8608
```

修复后（同一脚本）：

```
afterBackClick   hash=#/media  view=media  mediaHidden=false  mediaDetailHidden=true
events: []
```

#### 三、改动

- `app.js` 末尾补回丢失的 8 行（与 HEAD 完全一致，`diff` 校验 `TAIL_MATCHES_HEAD`）；`node --check` 通过。
- `index.html` 里 `app.js?v=20261023-grporder` → `...-grporder2`（否则浏览器命中旧的截断版本）。
- `cp` 到 `backend/target/classes/static/`（静态资源不需要重启后端）。
