## 讨论阶段（/grill-me 拍板）

需求：媒体细分 **媒体 → 媒体格式（视频/图片/文字）→ 子分类（视频：番剧/电视剧/美剧…）**，附快速维护功能，并优化。

| # | 决策 | 选项 |
|---|---|---|
| 1 | 根实体 | **全面改名 anime→media**（表/类/接口/前端/向量全链路） |
| 2 | 非视频粒度 | **单层媒体**：图片/文字无集/片段，仅 VIDEO 有 |
| 3 | 子分类 | **独立维护字典** `media_subcategory`，与 tag 词库并行 |
| 4 | 检索向量 | **格式筛选 + 全向量化**：搜索加 format/subcategory 过滤；非视频也入语义检索 |
| 5 | 格式字典 | **格式也可维护** `media_format`（带 has_children 标记） |
| 6 | 电影归属 | **电影=视频子分类**；旧 type 迁移 ANIME→番剧、MOVIE→电影 |
| 7 | 维护入口 | **下拉内联新建 + 列表「⚙管理格式」弹层** 双入口 |
| 8 | 优化 | 格式 tab 导航 + 按格式/子分类统计 + URL→格式/标题→子分类自动识别 |

设计文档 `docs/superpowers/specs/2026-08-04-video-tagger-media-format-design.md`，计划 `docs/superpowers/plans/2026-08-04-video-tagger-media-format-plan.md`。

## 执行阶段

- **Phase A 数据层**：V8 迁移（anime 加 media_format/subcategory、表改名 anime→media + media_tag/media_collection、关联列 anime_id→media_id、删 type、建字典表+种子、embedding_tasks 实体类型 UPDATE）；Anime→Media 系列实体/Mapper/Service/Controller 全面改名（sed 机械改名 + 语义拆分 type）；EntityType.ANIME→MEDIA（Milvus 前缀 "A" 保留，免迁移向量）。
- **Phase B 后端 API**：`/api/media*` 全端点 + list 增 format/subcategory 过滤；新增 `/api/media-formats`（格式树含每子分类媒体数、建/删格式与子分类、**删除保护**：被引用拒删）；SearchService 格式/子分类后置过滤（mixed/episode/clip 经父媒体解析）；StatsService 按格式/子分类分布；TitleParser 子分类探测（含集/季标记→番剧）+ ClipService URL→格式粗判。
- **Phase C 前端+扩展**：导航「番剧→媒体」、格式 tab（全部/视频/图片/文字，动态渲染）、筛选联动、管理格式弹层（左格式列表+右子分类 CRUD+新增格式）、新建/编辑媒体弹窗格式+子分类+内联「＋新建」、搜索格式/子分类筛选、统计格式/子分类分布卡片、非视频详情隐藏集列表；扩展响应字段 animeId/animeTitle→mediaId/mediaTitle。
- **Phase D 文档**：README（功能/架构/API）、CHANGELOG 加 v0.7.0、pom 0.6.0→0.7.0。
