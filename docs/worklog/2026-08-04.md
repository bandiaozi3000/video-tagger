## 讨论阶段（/grill-me 拍板）

需求：媒体细分 **媒体 → 媒体格式（视频/图片/文字）→ 子分类（视频：番剧/电视剧/美剧…）**，附快速维护功能，并优化。

| # | 决策 | 选项 |
|---|---|---|
| 1 | 根实体 | **全面改名 anime→media**（表/类/接口/前端/向量全链路） |
| 2 | 非视频粒度 | **单层媒体**：图片/文字无集/片段，仅 VIDEO 有 |
| 3 | 子分类 | **独立维护字典** `media_subcategory`，与 tag 词库并行 |
| 4 | 检索向量 | **格式筛选 + 全向量化**：搜索加 format/subcategory 过滤；非视频也入语义检索 |
| 5 | 格式字典 | **格式也可维护** `media_format`（带 has_children 标记） |
| 6 | 电影归属 | **电影=视频子分类**；旧 type 迁移 ANIME→番剧、MOVIE→电影 |
| 7 | 维护入口 | **下拉内联新建 + 列表「⚙管理格式」弹层** 双入口 |
| 8 | 优化 | 格式 tab 导航 + 按格式/子分类统计 + URL→格式/标题→子分类自动识别 |

## 媒体筛选不生效修复（未提交）

用户反馈：勾选格式/子分类仍显示全部。排查：**后端过滤 API 全正常**（`/api/media?format=IMAGE→0`、`format=VIDEO→3`；`/api/search?format=IMAGE→0`、`VIDEO→2`，curl 中文需 URL 编码）。**根因在前端**：`loadMedia` 在默认「最近观看」tab 走 `/api/media/recent?limit=50`，该端点不带 format/subcategory 过滤参数，收藏夹分支同理 → 过滤被完全忽略。

修复：`loadMedia` 取回列表后**客户端统一兜底过滤**（MediaSummary 自带 mediaFormat/subcategory，数据量小），recent 分支 limit 提到 100。已复制静态文件到 `target/classes/static`，浏览器需强刷（Ctrl+F5）绕过 app.js 缓存。
