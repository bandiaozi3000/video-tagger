# 2026-08-10 工作日志

## 网站设置功能（背景图轮播）+ 一轮 Bug 修复

**需求**：网站加「设置」，首个设置项 = 背景图（多图轮播）。用户先看方案（AskUserQuestion 拍板：header ⚙ 齿轮入口 / 后端持久化 / 多图 + 轮换时间 + 透明度 + 模糊），再实现。

### 设置功能实现
- **后端**：`V15__site_setting` 键值表（skey→JSON）、`SettingsService`/`SettingsController`（GET/PUT `/api/settings`、POST `/api/settings/bg` 多图上传落盘 `data/site/bg/`、DELETE 单张）、`/site/bg/**` 静态映射、`SettingsDTO`（bgImages/rotationSec/opacity/blur）。
- **前端**：header 右上 ⚙ 齿轮 → 设置弹窗（左侧分类 + 右侧内容）→ 背景图多图上传/缩略图列表/单张移除/移除全部、轮换时间(5-60s)/透明度/模糊滑块实时预览、保存 PUT；`site-bg` 背景层多图定时淡入淡出 + 深色遮罩；页面加载 `GET /api/settings` 自动应用。

### 背景图连踩 4 坑（用户实测逐个暴露）
1. **`key` 保留字**：MyBatis-Plus 生成 `SELECT key,value ...` 语法错误 → 500。V16 迁移把列改名 `skey`（V15 已执行不能改 checksum，只能加迁移）。
2. **transferTo 相对路径**：`data/site/bg` 相对路径下 `MultipartFile.transferTo` 落到 Tomcat 临时 work 目录，与 createDirectories 不一致 → FileNotFoundException。修复：siteDir 构造器转绝对路径。
3. **被 bg-fx 特效盖住**：`.bg-fx::before` 不透明深色渐变（`linear-gradient(#0c0c1a,#07070f,#0a0a17)`）全屏盖壁纸。Chrome 负 z-index 又被 body/canvas 背景挡。最终层级：site-bg(z-index:1) 盖 bg-fx(0)，main/footer(2) 在壁纸上，未设壁纸时 site-bg display:none 默认霓虹照常。
4. **透明度失效**：遮罩放在容器 `backgroundColor`，被子元素壁纸盖住。改 `::after` 伪元素遮罩 + `--mask-opacity` 变量（z-index 2 在壁纸上）。puppeteer 像素验证 opacity 0.3/0.6/0.9 → 亮度 70/130/190 递增。

### 视频导出 OOM（用户实测 node 退出 134）
- 根因：`render.js` 把所有抓帧 base64 缓存内存数组、最后统一写盘 → 素材多/视频长时（上万帧 × 200KB）撑爆 node 堆（~2GB）。
- 修复：**流式写帧**——`screencastFrame` 事件里边收边写盘（`f-%05d.jpg` 顺序落盘），内存 O(1)。实测 3 部 10s 720P 渲染成功（596 帧 59.6fps 产物 806KB）。

### 其他修复
- **@Async 自调用失效**（视频导出卡死）：`VideoExportTaskService.create()` 内 `this.runAsync()` 同类自调用绕过代理 → 渲染同步阻塞 POST 30s。注入 `@Lazy @Autowired self`，改 `self.runAsync(...)`。坑与 OmofunaSyncTaskService 注释一致。
- **删除健壮化**：`delete()` 删产物被 Windows 占用（播放器/资源管理器）时 AccessDeniedException 原被静默吞 → 重试 3 次 + 失败 `log.warn`（不再静默）。实测 data/exports 标准删除正常。
- **导出位置接上（从死代码复活）**：v0.13 的 File System Access API「选择导出位置」在 v0.18 改异步任务后成了死代码（产物固定 data/exports、前端无 createWritable）。修复：`/exports/**` 静态映射 + 前端导出时记住位置句柄 → 任务 DONE 后 fetch 产物写入所选位置（授权失效降级提示）。产物两份（data/exports 任务基石 + 所选位置副本），用户认可当前方案不进一步改。

### 决策
- 用户拍板：导出任务表**不落库**（内存表，重启丢记录但产物文件在）；导出产物**保持两份**（data/exports + 所选位置）；「只留一份」需后端拿路径（File System Access API 不给），暂不做。
