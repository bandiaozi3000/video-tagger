# 2026-08-31 工作日志

## v0.23 真实视频源、订阅与快捷播放

- 以 Superpowers 为唯一基准，将误标为 v0.24 的真实 Provider 设计与实施内容合并回 v0.23；后续只在用户明确声明时升级产品版本。
- 按顺序接入 Jellyfin、Mikan、动漫花园和声明式 Web Selector，所有真实 Provider 默认关闭。
- 新增受限同源 HTTP 客户端：拒绝跨源重定向、凭据 URL、未授权私网、超大响应，并统一映射登录和可重试错误。
- Jellyfin API Key 只作为 `X-Emby-Token` 发往固定源站；首版发现 Series/Episode 和来源页，不把令牌放入播放 URL。
- Mikan/动漫花园解析硬化 RSS，按字幕组聚合，保存集号、guid 和 torrent/enclosure 元数据，不启动 BT 引擎。
- Web Selector 支持配置式作品/分集 CSS Selector 与公开直接媒体解析，拒绝 HLS/DASH 和私网媒体。
- 新增 Provider 列表 API 和片源工作区数据源下拉框，页面打开仍不访问外部 Provider。
- `RealVideoSourceProviderTest` 10 项通过；追加 Animeko 网页源与源站回退测试后，最终 `mvn -q test` 全量 291 项通过，0 failure、0 error、0 skipped。
- JavaScript 语法、`git diff --check` 和密钥硬编码扫描通过；真实 Jellyfin/RSS/自定义站点因默认关闭且未提供端点与凭据，留给用户环境验收。

## v0.23 Animeko 式数据源链路追加

- 新增 MySQL V27、SQLite v09 的订阅、定义和用户实例表，并同步 baseline、MigrationTool 与迁移测试。
- 支持 Animeko `exportedMediaSourceDataList.mediaSources`，识别 `rss/v1` 与 `web-selector/v2`；外部订阅使用 HTTPS、2MB/200 项上限、秘密字段阻断、ETag/Last-Modified 和上次成功快照。
- 设置中新增数据源管理入口：推荐/自定义订阅预览、刷新、停用、来源兼容性、启用、排序和分步测试；管理接口不返回订阅快照，也不自动请求第三方图标。
- Episode 详情新增快捷播放：并发查询、500ms 状态轮询、自动选择、候选与来源状态抽屉、手动锁定、稳定播放后不静默换源。
- 临时候选只有点击“固定为 VideoAsset”时才保存片源包、确认 Episode 映射并创建 `REMOTE_STREAM` 资产。
- 产品版本保持 v0.23；除非用户明确声明升级，后续相关功能继续追加到 v0.23。

## v0.23 Animeko 网页源完整播放链路

- 修复 `web-selector/v2` 只导入不可执行的问题，新增 Animeko 作品、线路、分集和视频匹配配置适配器。
- 修复 `cookies: quality=1080` 被误判为秘密字段并清空整份配置的问题；Cookie 和自定义视频请求头改为剥离，不转发到第三方站点。
- 数据源列表新增单源配置抽屉，支持启用、播放优先级、配置摘要、保存和保存后测试。
- Episode 候选新增 `DIRECT`、`EXTERNAL`、`UNAVAILABLE` 播放模式：公开 MP4/WebM/Ogg 直放，无法安全解析时提供具体分集源站跳转。
- 使用 Animeko CSS 推荐订阅实测：18 个 `web-selector/v2` 均识别为可执行；叽哔动漫搜索到《败犬女主太多了！》并解析 12 个源项，Episode 第 1 集返回 4 个线路并成功跳转对应源站分集页。
