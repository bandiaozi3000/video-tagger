## 季上移媒体（Media.season）+ 片段季数展示

### 需求
- 片段展示「第几季」默认第一季；季数用正则（方案 B）从标题识别，识别不到默认 1。
- 「季」归媒体（Media.season），「集」归集（Episode.episodeNo）；编辑入口拆分：季→媒体编辑弹窗，集→集编辑（去季输入框）。

### 数据模型
- `media` + `season INTEGER NOT NULL DEFAULT 1`（季唯一权威来源）；`episode` 删 `season` 列。

### 正则
- `TitleParser.parseSeason(String)`：第X季（含中文数字）/ Season X / 第X期；识别不到返回 null。
- 触发时机：仅 Bangumi 同步「创建」媒体时 `MetadataSyncService.resolveSeason`（displayTitle→nativeTitle→别名，取首个命中，兜底 1）；手动编辑/同步更新不覆盖。

### 后端改动
- 实体/request：Media +season、Episode -season、MediaRequest +season（删过时兼容构造器，其 9 参签名与 canonical 撞型）、EpisodeUpdateRequest -season。
- 服务：MediaService.apply 默认 season=1 + get 传 season；EpisodeService.update/detail -season；ClipService.ensureEpisode 不再写 season；AnimekoTagService.label、VideoSourceQuickPlayService 改从 media.season 取。
- VO/Mapper：MediaDetail +season（兼容构造器补 null）；EpisodeDetail/EpisodeSummary -season；EpisodeMapper 4 处 @Select、ClipMapper.listByMedia 清 season 列/排序。
- 迁移：MySQL V31 + SQLite v13（media 加列 + episode 删列）；sqlite-schema.sql 同步；SqliteSchemaMigrator.inferVersion 加 media.season 判断；MigrationTool media/episode 列对齐。

### 前端改动
- index.html media-modal 加「季」输入框；app.js saveMedia/openEditMedia/reset 带 season。
- 片段详情 renderClipProfile 所属集改 `第N季 · 第M集`（季从 media 取，默认 1）。
- 集编辑 openEpisodeNoEditor 去季输入框；集详情 renderEpisodeProfile 集数改 `第M集`；renderEpisodeList 去按季分组（单媒体=单季，仅按集号排序 + 未识别集号组）。
