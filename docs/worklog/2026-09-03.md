# 工作日志 2026-09-03

## 媒体详情页 Demo 化重构（核心）

### 背景 / 诉求
- 用户反馈媒体详情页布局问题：`.container 1120` 锁窄、三栏分散、封面+元信息多处重复、外部资料独立卡片（v022 青色主题）。
- 用户明确要求：**完全按 Demo 布局重写，数据替换为真实 API**（不是打补丁/在旧 index.html 上改）。

### 过程（关键决策与踩坑）
- **定方案**：不走"在原有 index.html 结构上打补丁"，改用 Demo 的单容器渲染逻辑——`renderMediaDetail` 一次性生成 hero+信息流+集列表+右栏，渲染到 `#media-detail` 空容器。
- **结构重写（app.js `renderMediaDetail`）**：
  - 并行 fetch `/api/media/{id}` + `/episodes` + `/metadata-sync/media/{id}/metadata` + `/collections` → 一次生成完整 DOM。
  - Hero：封面(210px 窄列) | 标题+日文名+按钮行 + 简介(2行折叠+展开更多) + 题材/别名/关联(chip+更多)。
  - 集列表：双列网格卡（封面缩略图+标题+状态+⋯菜单）。右栏：档案信息/素材概览/标签池/收藏夹(行式)。
  - 保功能：按钮 id（detail-edit/rename/cover/sync/confirm/highlight/delete/materialize-batch）保留，改**事件委托**绑定（因为渲染前这些按钮不存在）。
- **index.html**：media-detail 区只留 `<div id="media-detail">`（删掉 detail-hero/detail-body 全部分散结构）。
- **踩坑 1（封面撑爆）**：CSS 写成了 `#media-detail-head .hero-cover`（旧结构选择器），但新渲染是 `.hero-top > .hero-cover`（无前缀）→ 封面没拿到 `width:210px` 撑爆。改为 `.hero-top .hero-*` + 补 `.hero` 卡片背景。
- **踩坑 2（集列表/右栏裸文本）**：`.section/.panel/.ep-*/.shelf-*/.asset-*/.tag-cloud` 这些类在 app.css **完全缺失**（renderMediaDetail 生成了但没样式）→ 从 `_demo-realtime.html` 补齐（这是"样式全没"的真正根因）。
- **踩坑 3（委托绑定 null 报错）**：`getElementById('detail-*').addEventListener` 在渲染前按钮不存在 → null，改 document 事件委托。
