## 一键打包脚本 + 工具链内嵌（便携版零依赖化）

**背景**：用户报桌面版"同步失败 Cannot run program node + 视频渲染启动失败"——打包版只内嵌 jre，node 靠系统 PATH（`RENDER_NODE_PATH` 默认 `node`），目标机没装 Node.js 就同步（omofuna 抓取 `node omofuna.js`）/导出（`node render.js`）全挂。且报错目录 `C:\Users\888888\AppData\Local\Temp\BNZ.xxx` = 在 Bandizip 里直接双击 zip 内 exe 运行（临时解压到 %TEMP%，数据会丢）——两个问题并存。

**改动**：
- `desktop/main.js`：`findNodePath()` / `findFfmpegPath()` **打包版优先内嵌** `resources/node/node.exe`、`resources/ffmpeg.exe`，开发模式逻辑不变。
- `desktop/package.json`：extraResources 的 jar 路径从硬编码 `../backend/target/video-tagger-backend-0.18.2.jar` 改为 `resources/app/video-tagger-backend.jar`（脚本拷最新 jar，升版不再改 package.json）；新增 `resources/node → node`、`resources/ffmpeg.exe → ffmpeg.exe` 两项。
- `desktop/pack.bat`（一键打包）：自动找 mvn（Maven wrapper dist 下含 mvn.cmd 的目录）→ `mvn package -Dmaven.test.skip` → 拷最新 jar → node 缺失则 npmmirror 下载（v22.20.0 win-x64，35MB，官方 nodejs.org 兜底）→ ffmpeg 从 `tools/` 拷 → electron-builder（skip signing）→ win-unpacked 改名 `VideoTagger/` → Compress-Archive 出 release zip。

**关键坑**：
- **bat 内中文 = 灾难**：UTF-8 中文字节在 cmd 默认 GBK 解析下配对错乱，吞掉换行/后续行首字符（报 `'fmpeg' is not recognized` 这种半词错）→ **bat 注释/echo 全英文（纯 ASCII）**。
- electron-builder 在**当前 cwd** 找 package.json → 脚本第 6 步必须 `pushd "%DESK%"`，否则从项目根启动就报 `Cannot find package.json in <root>`。
- 打包版退出时 `/actuator/shutdown` 404（jar 未暴露 shutdown 端点）→ 壳优雅关闭失效，走 taskkill 兜底（进程仍无残留，**老行为**，未修）。

**产物**：`release/video-tagger-desktop-0.1.0.zip` **490MB**（原 455MB；内嵌 node 35MB zip + ffmpeg 64MB，压缩后净增 ~35MB）。实测：解压根启动 health UP、`[dom]` desktopMode UI 全绿（hasSidebar 7 tabs / hasTitlebar 3 btns / hasStatusbar / desktopMode:true）、内嵌 jre 正确拉起 jar、退出干净。**Chrome 仍依赖目标机安装**（壳探测默认安装路径，无法内嵌）。
