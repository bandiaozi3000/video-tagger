# 2026-08-14 工作日志

## 桌面版改造（Web → Electron 桌面应用 + SQLite）全流程落地

### 背景与决策
用户需求：原生桌面体验、不想要浏览器访问、离线。经多轮决策（见 `docs/design/2026-08-14-desktop-port.md`）：
- 壳方案：**Electron**（经 WebView2+Java / Tauri / Electron 三方案对比；WebView2 无成熟 Java 绑定库是出局主因）
- 存储：**完全 SQLite**，MySQL 数据一次性迁移后退休
- UI：**复用现有 6500 行 vanilla JS 前端**（零重写，Electron 壳加载本地服务页面）
- 同步功能：暂不考虑（D9）；搜索召回：后置优化（D11）

### 实施过程（阶段 1~5 全部完成）

**① Electron 工程骨架（desktop/）**
- `main.js`：单实例锁 + 端口探测（9010 起，避开 8080 保留段）+ jar 定位 + spawn java -jar + 健康检查 + BrowserWindow + 三段式退出清理 + splash。
- **关键坑：Electron `will-quit` 不等待 async handler** → 子进程清理失效（Java 变孤儿）。改 `before-quit + event.preventDefault()` 阻塞式清理后才干净。
- preload 安全桥（contextIsolation + sandbox 开启）。

**② 存储层 SQLite 化**
- `sqlite-schema.sql`：18 张表 SQLite 建表 + 种子数据（media_format/subcategory 三格式九子类）。
- SQL 改造：`MATCH/AGAINST`（ngram 全文）→ LIKE 兜底（D11）；`CONCAT` → `||`；`INSERT IGNORE` → `INSERT OR IGNORE`（8 个 mapper）；`SUBSTRING_INDEX/FROM_UNIXTIME` → SQLite 等价改写；`IF()` → CASE WHEN。
- MybatisConfig 加 `PaginationInnerInterceptor(DbType.SQLITE)`。
- **关键坑：SQLite JDBC 不自动建父目录** → VideoTaggerApplication 加 `ensureDataDirs()`（VT_DATA_DIR 统一数据根）。
- 前端静态资源、`IFNULL`、`WITH RECURSIVE`、`LIMIT/OFFSET` SQLite 原生兼容，无需改。

**③ 数据迁移工具（MigrationTool）**
- 纯 JDBC 双连接：MySQL 读 → SQLite 写，保留原始 id 保证关联不破；18 表行数校验全对齐；封面目录整体拷贝（5526 媒体 + 5533 封面，0.9s）。
- **关键坑：SQLite JDBC `Statement.execute` 只执行第一条语句** → 按行累积、跳过注释、分号收尾 flush 逐条执行。
- **关键坑：schema 注释行与 CREATE 语句 split(";") 粘段被 `startsWith("--")` 误杀** → 逐行处理跳过纯注释行。
- 从 Spring Boot fat jar 跑自定义 main 用 `PropertiesLauncher`（`-Dloader.main=... org.springframework.boot.loader.launch.PropertiesLauncher`），java -cp 跑 fat jar 类加载不到 BOOT-INF 依赖。

**④ 桌面版集成**
- 首次启动迁移引导：无库 → 弹窗"从 MySQL 迁移 / 空库开始 / 取消"→ 跑迁移工具。
- 同步功能禁用（D9）：OmofunaSyncController `@ConditionalOnProperty(videotagger.sync.enabled)` + MediaController.syncAnilist 加开关判断。
- Electron `will-download` 接管：导出 HTML/视频弹"另存为"对话框 + 完成后打开所在文件夹。
- 视频导出工具链注入：壳检测 node/Chrome/ffmpeg 路径，环境变量注入后端（复用系统 Chrome + 本地 ffmpeg）。

**⑤ 打包分发**
- **JRE 未 jlink 裁剪**：jdeps 对 Spring/MyBatis/Jackson 反射加载类分析不全，裁剪风险高，改打包完整 JRE（包体 +300MB 换可靠性）。
- electron-builder 打 NSIS 安装器 `video-tagger-desktop-0.1.0.exe`（372MB）。
- **关键坑：electron-builder 默认下载 winCodeSign 卡死**（国内网络 + 7z 解压 symlink 需管理员权限）→ `--config.win.signAndEditExecutable=false` + `ELECTRON_BUILDER_BINARIES_MIRROR` 镜像解决。

### 桌面版 UI 改造（方案 C：标题栏 + 侧栏 + 状态栏）

用户反馈桌面版 UI 偏 Web 浏览器（顶部 header + 居中容器 + 底部 footer 是网页三件套）。经方案 A/B/C 三级对比，用户选 C（完整桌面化）。先出布局原型 `docs/design/2026-08-14-desktop-layout-C.html` 过目确认后落地。

**改造内容**：
- `index.html`：body 改为 `.shell` 三栏结构（`.titlebar` + `.main-body[.sidebar + .container]` + `.statusbar`）；tab 从顶部水平移到侧栏竖排（保持 `.nav .tab` 结构，`showView` 的 `.nav .tab` 选择器继续命中，逻辑零改动）；删 `site-footer`；`?v=20260814a` cache-bust。
- `app.css`：追加桌面化样式（titlebar/sidebar/statusbar/shell），沿用现有设计令牌（毛玻璃 blur(18px)、渐变、圆角 10-16px）；`body.desktop-mode` 触发 shell 布局 + 放开 container 宽度；隐藏 site-footer。
- `desktop/main.js`：主窗口 `frame:false`（无边框），加窗控 IPC（win:minimize/maximize/close + maximized-changed 通知）。
- `desktop/preload.js`：contextBridge 暴露 vtDesktop 桌面 API（platform/minimize/maximize/close/onMaximize）。
- `app.js`：检测 `window.vtDesktop` → body 加 desktop-mode + 绑定窗控按钮 + 状态栏填充（health 探测/媒体数/端口）。

**关键设计**：
- 桌面模式靠 `window.vtDesktop` 存在触发（Electron preload 注入），Web 版浏览器打开不触发，不影响 Web 版。
- tab 结构不变保证 `showView` 逻辑复用，纯 CSS/HTML 迁移。

**验证**：DOM 检查全绿（hasSidebar + 7 tabs / hasTitlebar + 3 btns / hasStatusbar / desktopMode:true），退出无 java 残留。

**遗留**：打包版需重新 electron-builder 才有新 UI（当前 jar 已含新前端，但 desktop/dist 安装包是旧的）。

### 数据/日志统一项目根 + 背景图上传修复 + 重新打包

**背景图上传失败根因**：SQLite 化改造重写 application.yml 时丢了 `spring.servlet.multipart` 配置 → Spring Boot 默认 max-file-size 1MB → 正常图片上传全被 413。恢复 `max-file-size: 10MB / max-request-size: 12MB`，实测 2MB 图上传成功。

**数据目录统一项目根**：用户要求"所有数据存项目根"。壳 `resolveDataDir()`：
- 开发模式 → 项目根 `data/`（与 Web 版共用：5526 条库 / 5533 封面 / 3 张背景图统一）
- 打包模式 → `%APPDATA%/video-tagger/data`（安装目录只读）
- 数据库迁移到 `data/video_tagger.db`；背景图目录统一后桌面版能读到 Web 版时代的上传。

**日志落盘**：后端日志 `data/logs/video-tagger.log`（application.yml `logging.file.name` 跟随 VT_DATA_DIR）；壳 + 后端输出 `data/logs/desktop.log`。ensureDataDirs 加 logs。

**⚠️ Electron segfault 坑**：在 main.js 顶层 `console.log = ...` 拦截做日志落盘，打包版直接 Segmentation fault（asar 内同步 fs 操作触发原生崩溃），开发模式正常。**移除顶层 console 拦截**，改在 startBackend 里对后端输出显式 `fs.appendFileSync` 落盘后正常。

**打包**：dist5/video-tagger-desktop-0.1.0.exe（379MB）验证通过（启动/数据目录/日志全正常）。打包时若旧 dist 被锁（残留 bash cwd），用 `--config.directories.output=distN` 输出到全新目录绕过。
